Start Step 2: the .cube parser

Step 2 is the LUT engine. This lands the part everything else depends on: parsing
and validating an Adobe .cube file. It is pure text, so the whole of it is covered
by unit tests on CI with no device, which is the point — a LUT that will be
rejected should be rejected by the build, not by a user.

Processing/CubeLUT.swift
- The parsed table, split into 1D and 3D kinds. They are not interchangeable and
  Step 2 only applies 3D, so a 1D table does not report itself as usable.
- The domain is recorded as declared or assumed. A .cube with no DOMAIN lines means
  sRGB 0..1, and that is an assumption, so it is visible rather than implied.
- isUsable requires the sample count to match the declared size, so a truncated
  file cannot pass itself off as applyable.

Processing/CubeLUTError.swift
- Every case carries the line that caused it, and exposes it as a separate property
  so an import preview can point at the offending line. A message with no location is
  not actionable.

Processing/CubeLUTParser.swift
- Total: every input produces a table or an error, never a half-filled one.
- No silent repair: a sample outside the file's own declared domain is an error, not
  a clamped value, because clamping bakes a wrong look into every photo taken with
  the style.
- A data line is identified by every token parsing as a number, not by looking for a
  leading keyword, so lowercase directives and digit-leading samples both work.
- An unknown UPPERCASE keyword is treated as a vendor extension and skipped, since
  real .cube files carry them. A lower-case token that is neither a number nor a known
  directive is damaged data and is reported, because the Adobe spec puts every
  directive in caps and that casing is what separates the two cases.
- A 65-cubed table is rejected: it is 2.7 M samples and roughly 11 MB of texture.
  33-cubed is what shipping LUTs use.
- parse(data:) exists so UTF-8 decoding has one honest error name; a JPEG renamed to
  .cube is the common way to arrive with bytes that are not text.
