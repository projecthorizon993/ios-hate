Correct the Android diagnostics constants, one numeric type, and the ViewModel factory

Camera2 has no REQUEST_AVAILABLE_CAPABILITIES_MANUAL_SENSOR_BLOCKED and no
..._RAW_SENSOR. The real names are ..._MANUAL_POST_PROCESSING and ..._RAW, so a
device advertising neither now reports the absence instead of failing to compile.

AE_TARGET_FPS_RANGE is a Range<Int> and ReportFormat.number takes a Double, so
both bounds are widened.

viewModelFactory { initializer { ... } } already returns a
ViewModelProvider.Factory. Wrapping it in Factory.from() was a type error and a
no-op, and the now-unused import is gone.

Also dropped a test that asserted a P3 lookup table can be applied to a P3
image. A .cube domain of 0..1 means gamma-encoded sRGB and the format cannot
say otherwise, so there is no such table; the refusal is asserted instead, and
the test now records that the explicit logged conversion is not built yet.
