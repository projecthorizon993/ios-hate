Copy the LUT sample buffer as bytes, and surface Gradle's real cause

Data(lut.samples) does not compile: Data initialises from bytes and Float is
not UInt8. CIColorCube wants the raw 32-bit float bit patterns, so the sample
buffer is copied verbatim through withUnsafeBufferPointer. A test asserting the
byte count was also wrong by a factor of three, missing the RGB per sample.

Android: Gradle puts the actual cause on the line after '* What went wrong:',
with no prefix, so a grep for known prefixes produced an annotation reading only
the header. The block after the header is now extracted, so the reason arrives
with it.
